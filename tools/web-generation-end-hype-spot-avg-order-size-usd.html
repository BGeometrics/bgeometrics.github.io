Hyperliquid (HYPE) Spot Average Order Size

Average size of the trades in the HYPE/USDC spot pair on Hyperliquid, the main spot market for HYPE, in USD.

It is calculated by dividing the daily trading volume by the number of trades. The volume is converted to USD with the typical price of the day (high + low + close) / 3.

Average Order Size = Daily Volume / Number of Trades

Larger average sizes suggest more participation from large holders (whales) buying or selling in the spot market; smaller sizes point to retail activity. Compare it with the average order size in futures.
